# Documentacao do Projeto

Estrutura sugerida:

- `00-governanca/`: visao geral, glossario, convencoes e decisoes gerais.
- `01-prd/`: PRDs e revisoes de escopo.
- `02-arquitetura/`: ADRs, diagramas, visao de componentes e contexto.
- `03-produto/`: regras de negocio, personas, jornadas e fluxos.
- `04-backend-rust/`: padroes, modulos, contratos de API e guias backend.
- `05-frontend-dioxus/`: design system, navegacao, componentes web.
- `06-mobile/`: decisoes e guias Android/iOS em Dioxus.
- `07-dados-migracao/`: schema canonico, ETL, reconciliacao e cutover.
- `08-integracoes/`: integracoes externas e contratos (incluindo sync service).
- `09-qa-testes/`: estrategia, planos e evidencias de teste.
- `10-devops-observabilidade/`: deploy, monitoramento, logging, incidentes.
- `11-seguranca/`: autenticacao, autorizacao, auditoria e compliance.
- `12-gestao-projeto/`: roadmap, backlog, milestones e status reports.
- `13-runbooks/`: operacao, troubleshooting e procedimentos de suporte.
